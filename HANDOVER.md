## Domain cutover — `up-desk.online` (do in this order)

The code is already migrated. To go live:

1. **DNS** (at the registrar where you bought it): add an **A record**
   `@` (or `up-desk.online`) → **`13.234.64.162`**. (Optional: `www` CNAME.)
   Wait for it to resolve: `nslookup up-desk.online` shows the EC2 IP.
2. **Server / Caddy** (SSH to EC2): set the site to the new domain and reload.
   The repo `infra/caddy/Caddyfile` is already `up-desk.online { reverse_proxy 127.0.0.1:8080 }`.
   Copy it into place (e.g. `/etc/caddy/Caddyfile`) and `sudo systemctl reload caddy`
   — Caddy provisions a Let's Encrypt cert automatically (port 80+443 must be open).
   Verify: `curl -I https://up-desk.online` returns a valid cert.
3. **coturn** — no change needed (it binds the IP); the TURN hostname
   `up-desk.online` now resolves to the same box. Keep `external-ip=13.234.64.162`.
4. **Rebuild all apps** (they now use `wss://up-desk.online` + `turn:up-desk.online`
   and the WebView2 SPKI cert-pin was removed since the LE cert is trusted). See
   `docs/DEPLOY-AND-BUILD.md`.
5. Decommission DuckDNS (optional) — `infra/duckdns-keepalive.sh` is no longer used.
